Frequently Asked Questions

What file formats are supported?

We support 190+ conversion paths across 8 categories: Documents (PDF, DOCX, DOC, ODT, TXT, RTF, MD, EPUB), Images (JPG, PNG, WEBP, TIFF, BMP, GIF, HEIC, HEIF, SVG), Spreadsheets (XLSX, XLS, ODS, CSV), Presentations (PPT, PPTX, ODP), Audio (MP3, WAV, FLAC, AAC, M4A, OGG), Video (MP4, MKV, MOV, AVI, WEBM, FLV), Archives (ZIP, RAR, 7Z, TAR), and Data formats (JSON, XML, YAML, HTML).

Is my data safe and private?

Absolutely! We don't store any conversion history or your files permanently. All files are processed on our server with UUID-based filenames and are automatically deleted immediately after download. Unclaimed files are deleted after 60 minutes. We never keep copies of your files or track your activity.

What is the maximum file size?

The maximum file size is 50MB. This limit ensures fast processing and optimal performance for all users. If you need to convert larger files, consider compressing them first or splitting them into smaller parts.

How long does conversion take?

Most conversions complete in seconds. Document conversions typically take 5-30 seconds, image conversions are near-instant, and video conversions may take up to 2 minutes depending on the file size and format. If a conversion exceeds the timeout limit, an error message will be displayed.

Why can't I convert my file to a certain format?

Not all format conversions are technically feasible or meaningful. For example, you cannot convert an audio file (MP3) to a document format (PDF) as they contain fundamentally different types of data. The "To Format" dropdown automatically shows only compatible output formats based on your input file type.

What happens if conversion fails?

If a conversion fails, you'll see a clear error message explaining the issue. Common causes include corrupted files, unsupported format combinations, or file size issues. You can try uploading a different file or choosing another output format. If problems persist, our system may need certain dependencies installed (LibreOffice, ffmpeg, etc.).

Do files expire?

Yes. Converted files are automatically deleted after download to protect your privacy. If you don't download your file, it will expire after 60 minutes. A cleanup process runs regularly to remove old files. You can always re-upload and convert again if needed.

Is this service free?

Yes! Our file conversion service is completely free with no hidden costs or limitations on the number of conversions. You can convert unlimited files within the 50MB size limit. We believe in providing accessible tools for everyone.
