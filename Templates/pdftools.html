Frequently Asked Questions

What file formats do you support?

We support PDF files exclusively for our PDF tools. Supported versions include PDF 1.0 through PDF 2.0, including password-protected PDFs (with password provided). Files can be up to 100MB in size.

How long does processing take?

Processing times vary by operation. Simple operations like metadata viewing are instant. Text extraction takes 10-30 seconds. Large file compression may require 1-5 minutes.

Can I use these tools on mobile devices?

Yes, our PDF tools are fully responsive and work seamlessly on smartphones and tablets.

How do you handle password-protected PDFs?

For password-protected PDFs, you'll need to provide the document password during upload. The password is used only for decryption and is never stored or logged.

What happens if I don't download my processed file?

Processed files are available for download for 60 minutes. After that, all files and processing data are automatically and permanently deleted.

What if processing fails?

If processing fails, you'll receive a detailed error message. Our system automatically cleans up any failed processing attempts.

Can I process multiple files simultaneously?

Some tools like PDF merging support multiple file inputs. For other tools, you can open multiple browser tabs to process several files concurrently.

Will processing affect PDF quality?

Most operations preserve original quality completely. Compression tools offer quality settings to balance file size with visual fidelity.
