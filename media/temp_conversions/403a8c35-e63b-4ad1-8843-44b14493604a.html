Frequently Asked Questions

What file formats are supported?

We support conversions between Documents (PDF, DOCX, TXT, ODT), Images (JPG, PNG, WEBP, TIFF), Spreadsheets (XLSX, CSV, XLS), and Videos (MP4 to MP3/GIF). The available output formats depend on your input file type.

Is my data safe and private?

Yes! We don't store any conversion history or your files. All files are processed on our server and automatically deleted after download or after 60 minutes, whichever comes first. We never keep copies of your files.

What is the maximum file size?

The maximum file size is 50MB. For larger files, please consider compressing them first or splitting them into smaller parts.

How long does conversion take?

Most conversions complete in seconds. Complex conversions like video processing may take up to 2 minutes. If a conversion takes longer than expected, please try again or contact support.

Why can't I convert my file to a certain format?

Some conversions aren't technically possible or supported. For example, you cannot convert an MP3 audio file to a document format. The "To" dropdown only shows formats that are compatible with your input file.

What happens if conversion fails?

If a conversion fails, you'll see an error message explaining the issue. Common causes include corrupted files, unsupported formats, or file size issues. You can try uploading the file again or choose a different format.
